## 相比 Production v0.1.0 新增

- 小飞配置、知识、客户、会话和事件按 Organization 隔离。
- 新增商户 → 客户 → 会话三级后台管理和客服工作台。
- 新增全局 Admin 的商户、小飞启用状态、客户、会话和事件总览。
- 新增可靠 S2S 消息接收与事件监控，可查看事件时间、首次接收、最近投递、
  完成和更新时间。
- 新增 Email/WhatsApp Mock Worker，可验证入站消息、客户和会话落库、小飞
  回复、重复消息处理和回声抑制。
- UAT 登录页提供一键初始化和多角色虚构测试账号。

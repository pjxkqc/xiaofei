## 主要功能

- 客户无需登录即可与小飞对话，会话持久化保存。
- 客服可以查看会话、在线状态、关注状态和接管状态，并进行真人回复。
- 支持 MD/TXT、PDF、DOCX、XLSX、网页和手工问答知识录入。
- 支持知识条目、知识单元、能力审核、Eval 和会话验证闭环。
- Mastra 负责受治理的回复生成，LangGraph 负责会话流程编排；最终回复仍需
  经过 Guardrail 和 Owner 校验。
- 支持多轮上下文、知识未命中时继续接待，以及后续重新命中知识后的恢复。

Production 不提供一键测试账号，也不保存共享测试密码。需要后台访问时请使用
个人账号正常注册或登录。

UAT 已经包含后续的 Organization、客户、会话、消息事件和 Mock Worker 能力，
但这些功能尚未发布到 Production。最新 UAT 状态见
[`README.md`](./README.md#accepted-uat-candidate)。
